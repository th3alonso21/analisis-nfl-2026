# Análisis NFL 2026

Página personal de análisis de la temporada 2026 de la NFL: pronóstico de cada partido, análisis por jugador, tabla de equipos y lesionados.

- Entra con Google; solo las cuentas autorizadas pueden ver los datos.
- Los datos se guardan en Firebase (no en este repositorio).
- Estadísticas: datos de juego oficiales de la NFL vía nflverse.

Página no oficial ni afiliada a la NFL.
